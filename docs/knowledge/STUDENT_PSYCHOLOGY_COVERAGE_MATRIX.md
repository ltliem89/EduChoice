# STUDENT PSYCHOLOGY — COVERAGE MATRIX (Bản đồ phủ 36 miền × 72 chủ đề)

> Bản đồ đối chiếu: **36 miền (domains)** nhóm theo **6 mảng** (A-F) × **72 chủ đề** (§5) với file
> hiện có trong kho + các quick-consultation card mới (`psy-sit-XX`). Dùng để: (1) biết miền nào
> đã phủ, (2) ưu tiên bổ sung ở giai đoạn 3X, (3) dẫn đường RAG/document chaining.

## 0. Cấu trúc nhóm (A–F theo §5)

- **A. Cognitivo / Học tập & Tư duy** (1–6)
- **B. Emociones / Cảm xúc** (7–16)
- **C. Conducta / Hành vi học đường** (17–26)
- **D. Social / Xã hội & Bạn bè** (27–31)
- **E. Familia / Gia đình** (32–36)
- **F. Transversal / Bối cảnh & Hạ tầng** (wellness/context)

> Mỗi miền = 1 nhóm chủ đề lớn; mỗi miền lại chia 2 chủ đề con (72 chủ đề tổng). Bảng bên dưới
> theo miền + chủ đề, đánh dấu file hiện có / card tư vấn nhanh.

## Phần tổng kết phủ (gaps)

- Trực tiếp theo miền §5 trước giai đoạn 3X: **9/36 miền (~25%)** có file tri thức trực tiếp —
  A1-6 (một số), B7, B8, C17-26 (một số) → 3X mở rộng thêm cards + tài liệu hệ thống.
- Miền YẾU nhất (thiếu file trực tiếp, gap đỏ): **E35-E36** (safeguarding/bao vệ trẻ em),
  **D27-D28** (bắt nạt/loại trừ — chỉ wellness lỏng), **F** (an toàn), **C18** (trốn học).
- Sau đợt 3X (v2.1): bổ sung core system docs + 23 cards `psy-sit-01…23` → phủ hầu hết
  miền B, C, D, E bằng card tư vấn nhanh + 2 protocol (SAFETY/SAFEGUARDING).
- **Còn trống (ưu tiên sau)**: file tri thức chuyên sâu cho §36 (quy trình safeguarding đầy đủ),
  §12 (bắt nạt chi tiết), §41; cần hoàn thiện từ `KNOWLEDGE_V2` + `SAFETY_PROTOCOL`.

## Ưu tiên S/H/M (trích từ mục tiêu 3X)
- **S (Bắt buộc ưu tiên)**: bắt nạt/cyberbullying/bao vệ (psy-sit-08), tự hại/tự sát (20),
  xâm hại/safeguarding (21), loại trừ xã hội (15), bạo lực học đường (08), trốn học (07).
- **H (Cao)**: lo âu thi cử (10,13), kỳ vọng cha mẹ (11), ly hôn (16), mất động lực (05),
  khí sắc thấp (02), giấc ngủ (17), nội trú/DTTS (19).
- **M (Trung bình)**: các construct/toolkits detail, cầu toàn, giao tiếp bạn bè, kỹ năng học tập.
